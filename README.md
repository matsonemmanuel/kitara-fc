# Kitara FC Website

A responsive React + Vite + Tailwind CSS homepage concept for Kitara Football Club.

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for deployment
Run `npm run build`. The production site will be generated in `dist/`.

## Before publishing
- Replace the demo Unsplash photos with approved Kitara FC photography.
- Confirm official social media URLs, club contact email and any official ticket links.
- Update the fixture section with verified match dates, opponents, venues and kick-off times.
- The newsletter form is a frontend demo; connect it to a backend or mailing-list provider to collect subscriptions.
- The dropdowns and page section links are starter navigation. Build dedicated routes/pages as the site expands.
